# Session review and confirmed saves (#96)

Both modes retain a review draft keyed to the session, including on reload. Personal review leaves clean BPM blank unless there is a confirmed checkpoint; reflections are explicitly player observations. Studio review retains scoped material identities, optional unmeasured values and the existing partial/pain counting rules. The saved finish reports the log action and offers Today or Coach without claiming improvement.

Each new session has a persisted random submission id. Both log writers serialize a workspace's saves and publish complete, synced bytes through an exclusive hard link. The submission id is recorded in the log frontmatter. Concurrent retries and a retry after a server restart find that original log instead of writing another. A retry keeps the original data and reports that later edits were not applied. Legacy clients without an id keep exclusive date/sequence naming. One app process must own each workspace, as before; multi-process workspace writers are not supported.

Automated checks include concurrent save retries and exclusive log publication, existing personal/Studio parsing/counting tests, and draft restore tests. The stage-tempo smoke covers Quick, Full and Short reviews, skipped/unmeasured stages, neutral exit/resume/discard, retained takes, failed saves, lost success responses, retry/reload and saved-log readback. Old navigation/start/pane selectors are updated to the current UI. Full typecheck/test/build and scratch browser results are recorded with this delivery. No owner vault or live model is used.
