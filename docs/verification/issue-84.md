# Hosted sign-in boundary (#84)

Hosted mode is a separate, opt-in shell. It registers no personal or Studio handlers, does not initialize a Studio, starts no model and never returns owner app-info. All private routes return 401 without a live session and 503 with one until their account-scoped implementation lands. Health, account status, sign-in/callback and the public build shell/assets are the explicit allowlist.

Configure `STRUNA_MODE=hosted`, `STRUNA_HOSTED_ORIGIN` (exact HTTPS origin), `STRUNA_OIDC_ISSUER`, `STRUNA_OIDC_CLIENT_ID`, `STRUNA_OIDC_SECRET_FILE` and an independent `STRUNA_STATE_DIR`. Use a new scratch home/cache as well. Missing configuration refuses startup. Hosted defaults never use personal legacy state/cache fallbacks. This does not configure or advertise Google, Apple or email. Provider registration, focused security review and owner approval are required before public exposure; private-data enablement remains blocked by later isolation work.

The maintained openid-client 6.9 adapter uses discovery, authorization code, S256 PKCE, state, nonce and validated ID-token claims. Only issuer/subject maps to an opaque account id. The identity SQLite database holds hashed random sessions, seven-day idle/thirty-day absolute expiry and revocation. Secure Host-prefix cookies are HttpOnly, SameSite=Lax and Path=/. Login rotates the current browser session. Logout checks exact Origin, the app header and a session-bound CSRF token before revocation. Return destinations are named app hashes. Attempts are browser-bound, expire in ten minutes and are consumed once. Login rate limiting gives each browser 30 attempts per ten minutes and the instance a separate 1,000-attempt aggregate bound. Callback replay cannot consume another browser’s login quota. A production proxy must also limit requests before the app.

Automated scratch HTTP coverage: two independent identities; owner-header rejection; all private route classes denied; cross-origin login; callback browser binding, mismatch, failure, expiry and replay; session rotation, logout replay, idle expiry, forged return targets and rate limiting. Typecheck, full tests and production build run for this PR. No real provider registration, production cookies or real account is qualified by these fixture tests.

The hosted React branch mounts no private components or cache. Account status refreshes on focus; sign-out reloads component state and clears sessionStorage. Later data-route work must partition its private caches by account before enabling them. Guest browser-local work has a separate storage owner.

Rollback: leave hosted mode disabled and run the existing personal/Studio configuration; do not reuse a hosted identity database as an owner database.
